{# Each swatch below must use a literal, complete `bg-*` class (not a dynamically built one, and not an inline `style="...var(--color-X)"`) - Tailwind's v4 CLI only emits a @theme CSS variable into the compiled stylesheet when it sees a real utility class referencing it somewhere in the scanned template source. A class built from a Jinja variable (`bg-{{ var }}`) never matches, because the scanner reads raw file bytes looking for complete class-shaped tokens, and `{{`/`}}` breaks the token before the suffix - so neither "bg-" nor the bare word "steel" register as a used class on their own. Steel and Regolith had no other `bg-steel`/`bg-regolith` usage anywhere in the app, so they were the only two tokens with no path to being emitted, and rendered as empty (unset custom property) swatches. Listing the full class name as a literal string in this loop's data (even inside a Jinja `{% for %}` list literal) is enough - the scanner matches on raw text, not on Jinja/HTML structure. #}

PLANET-SCALE BUILDINGS

Currently LIVE on /colony. Each building is a small (6-20 pixel) cluster redrawn in the original bake's own style and positioned at the real rim spot its corresponding original cluster already occupied, so built up to LV3 the planet reproduces the original bake almost pixel for pixel. Same anchor at every level - LV1/LV2 just reveal an ordered prefix of the full cluster (base pixels first, lit/accent pixels last), never a different shape or a new position. No background, no outline - every pixel that isn't part of a cluster is the sphere's own rust. LV1 is a readable 6-8px structure for every type (fixed after a review found the original LV1 nearly invisible at 1-3 pixels).
